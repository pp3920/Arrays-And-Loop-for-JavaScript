How did you approach creating more flexible functions with parameters?

I focused on making functions reusable by passing parameters instead of hardcoding values. This helped me control what data goes into the function and made the logic more dynamic. It also improved my understanding of how different inputs affect the output, making the code easier to test and reuse.

What challenges did you face while incorporating conditional logic in your functions?
The main challenge I faced was handling correct syntax and writing proper conditions. Sometimes I made mistakes with operators (like = vs == or ===) and logical conditions. I also had to think carefully about edge cases, such as missing or invalid inputs.
